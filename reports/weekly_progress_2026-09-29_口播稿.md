## 01 总览

这周我的工作主要围绕一件事：把现有的 AAOCA 病历资料整理成能查到原文、能按患者浏览、也能继续做人工复核的研究证据。目前队列有 232 行患者清单，关联到 342 份唯一 PDF。完整处理后得到 13,931 个结构化章节和 10,341 条按文书日期排列的时间线条目。

这一周形成了三项交付：一条可重复运行的文本处理流程；带原文定位的治疗状态候选结果；以及病例浏览、Gold Set 审阅和例外病例复核的交互入口。下面按这三个层次展开。

## 02 数据底座

原始资料是分散的 PDF，所以第一步是把患者清单、文档和正文对应起来，再做去重、文字提取、必要的 OCR、章节识别和日期整理。365 个文件路径去重后是 342 份唯一内容，其中 231 位患者匹配到 PDF。

这条流程的关键价值是回查：从一条时间线记录，可以找到对应章节，再找到原 PDF 的页码。完整快照中的非空文本行，章节覆盖缺口和重复覆盖都是 0。现在我们可以按患者和文书类型查看资料，也可以定位手术、检查等相关文本。

## 03 病例相关性与治疗字段

在治疗字段上，我先把 AAOCA 相关性和实际治疗分开处理。232 位患者中，自动筛出 230 位相关、2 位不确定；其中 62 位进入例外复核队列。

对于 230 位自动相关患者，目前规则抽取给出四组候选状态：111 位有已完成 AAOCA 手术的证据，11 位是拟或建议手术，20 位有明确保守证据，88 位状态未知。每个判断都能回到原文位置；本轮总共保留了 1,619 条治疗证据。例外复核工作簿已经备好，下一步是和医生一起核对这些边界病例。

## 04 真实病例

这两例说明为什么需要把“提到手术”和“做过 AAOCA 治疗手术”分开。病例 A 的病程写着需要择期手术，但实际完成的操作记录是诊断性冠脉造影，所以目前归为拟手术，实际 AAOCA 手术状态仍是未知。

病例 B 的诊断列表出现冠状动脉畸形，但手术记录写的是室间隔缺损和卵圆孔修补。这是已经完成的其他手术，不能直接填成 AAOCA 治疗手术。病例浏览器里可以用页面上的患者 ID 找到原文和 PDF 页。

## 05 验证与 LLM 试跑

流程方面，完整文本快照和治疗抽取包都通过了结构与来源校验，错误和警告均为 0。人工评测方面，Gold Set 已经固定抽取 48 页，覆盖原生文字与 OCR、病历与检验四个层次；逐页人工标注还要继续推进。

我昨天还对 LLM prototype 做了 11 条响应的小样本试跑。1 条通过校验，10 条被拦截；一共记录 52 项校验错误，其中证据 ID 错用和引文区间不匹配各有 15 次。这轮结果给出了很具体的修复方向：让模型引用正确的证据 ID、对齐原文区间，并保持治疗状态前后一致。修好后，再用人工标注样本评估效果。

## 06 研究切口

研究方案也做了一轮收敛。原来比较宽泛的“预测是否手术”，现在聚焦到一个决策前问题：对于同一患儿、同一批当时可见的候选证据，在固定只展示三条的条件下，应该先给医生看哪三条？

方案分三步。先核实病例和影像覆盖、决策时间、文书可见时间，以及医生如何定义“继续保守”和“升级评估”；然后用同一候选池、同一展示预算比较不同证据排序方法；如果排序确实有收益，再看这些证据能否改善后续行动建议。当前文本底座已经能提供章节、日期和来源指针，接下来要和临床及影像同学一起把决策前的时间边界定清楚。

## 07 交互入口

这里准备了三个入口。病例浏览器可以从队列总览进入某位患者的时间线，展开章节，再回到 PDF 页；Gold Set 审阅台可以对照原始 PDF、文字和分段预测，逐页校正；例外复核表收集了 62 位待审患者和相关证据，适合和医生一起确认结论。

**建议现场操作：**打开病例浏览器，用上一页病例 A 的患者 ID `p_c928419ed1c239ea` 搜索，展示“病程中的择期手术”与“实际冠脉造影记录”如何分别定位。如果时间充裕，再打开 Gold Set 审阅台，展示一页 PDF 与文本的对照。

## 08 下一步

下一步有三件事。第一，和医生确认研究中的具体决策点、行动边界和索引时间。第二，推进 48 页 Gold Set 与 62 位例外患者的人工复核，优先看治疗未知和日期冲突的病例。第三，和影像同学对齐 CTA、心超的患者覆盖与检查时间。

文本侧现在已经能支持发现证据、定位来源和组织人工复核。完成临床定义、影像对齐和小样本标注后，就可以把这些资料用于更清晰的决策前证据排序实验。
